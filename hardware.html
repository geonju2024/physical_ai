Rational Architecture Case Studies

Every Component Has a Purpose.

기술을 과시하기 위한 부품은 단 하나도 없습니다. 실제 가정 환경에서의 사용자 문제점을 명확히 정의하고, 이를 완벽하게 해결하기 위해 선택된 5가지 엔지니어링 결정 사례를 소개합니다.

CASE STUDY 01

Edge AI Processing

개인정보 로컬 완결성
01 / 사용자 문제 (USER CHALLENGE)

스마트미러는 침실과 드레스룸에 설치됩니다. 옷을 갈아입거나 가벼운 옷차림의 고화질 원본 사진이 외부 클라우드 서버로 업로드되는 것은 치명적인 프라이버시 침해 우려와 거부감을 유발합니다.

02 / 선택한 기술 (SELECTED TECH)

NVIDIA Jetson Orin NX 16GB (100 TOPS)를 기기 내에 실장하여 포즈 추정(YOLOv8-pose), 인체 세그멘테이션(SCHP), 의류 특징 임베딩 모델을 기기 내에서 로컬 연산하도록 설계했습니다.

03 / 기대 효과 (ENGINEERED OUTCOME)

원본 이미지는 기기 내부 메모리에서 처리 후 즉시 소멸되며, 오직 암호화된 512차원 특징 벡터 데이터만 추천 API로 송신됩니다. 프라이버시를 100% 보장하며 응답 속도 2초 이내를 달성합니다.

CASE STUDY 02

Accurate Distance

광학 왜곡 방지 및 전신 추정
01 / 사용자 문제 (USER CHALLENGE)

사용자가 거울에 너무 가깝거나(1.5m 이내) 멀리 있으면 발목이나 머리가 잘려 정확한 신체 비율 측정과 가상 피팅(VTO)이 불가능하며, 단안 RGB 카메라만으로는 실측 신장 계측에 오차가 큽니다.

02 / 선택한 기술 (SELECTED TECH)

Intel RealSense D455의 넓은 FoV(86°×57°)와 TFmini-S ToF 레이저 센서를 융합했습니다. ToF로 초당 100회 정밀 거리를 계측하고, D455로 2.0~2.5m 거리의 3차원 깊이 맵을 동시 추출합니다.

03 / 기대 효과 (ENGINEERED OUTCOME)

거울 UI가 "한 걸음 뒤로 물러서 주세요"와 같은 직관적 피드백을 실시간 제공하며, 전신이 온전히 유효 범위(1.9~2.6m)에 들어왔을 때만 촬영을 트리거하여 피팅 오차율을 3% 이내로 제어합니다.

CASE STUDY 03

Controlled Lighting

의류 색상 & 피부톤 왜곡 극복
01 / 사용자 문제 (USER CHALLENGE)

가정 내 조명 환경은 백열등(2700K 따뜻한 주황색)부터 형광등(6500K 푸른빛)까지 천차만별입니다. 동일한 감색(Navy) 재킷이라도 조명에 따라 검은색이나 회색으로 오인식되어 잘못된 코디가 추천됩니다.

02 / 선택한 기술 (SELECTED TECH)

5000K 고연색 COB LED (CRI 95+)를 거울 양측에 1.5m 배치하고, ams TCS34725 RGBC 센서로 주변 색온도를 측정해 촬영 직전 보조광으로 플래시 점등 및 von Kries 색보정을 병행합니다.

03 / 기대 효과 (ENGINEERED OUTCOME)

어떠한 실내 조명 하에서도 태양광에 준하는 기준 백색광(5000K) 환경을 일관되게 형성하여, 의류 원단의 섬세한 텍스처와 미묘한 퍼스널 컬러 톤을 스튜디오 수준으로 정확하게 재현합니다.

CASE STUDY 04

Privacy-Aware Capture

상시 촬영 불안감 원천 차단
01 / 사용자 문제 (USER CHALLENGE)

카메라가 상시 켜져 있는 스마트 디바이스는 사생활 감시 공포를 초래합니다. 사용자는 자기도 모르는 사이에 사진이 찍히거나 저장되고 있다는 불안감을 해소할 물리적 장치를 원합니다.

02 / 선택한 기술 (SELECTED TECH)

PIR 센서는 화면을 깨우는 앰비언트 모드에만 사용하고, 32인치 IR 터치 프레임의 명시적 버튼 터치 혹은 고유 제스처가 감지될 때만 0.5초 동안 카메라 전원 및 캡처 파이프라인을 기동합니다.

03 / 기대 효과 (ENGINEERED OUTCOME)

카메라 센서는 99%의 시간 동안 완전한 절전 및 셧다운 상태를 유지합니다. 사용자가 거울을 직접 터치해 의사를 표현했을 때만 점등 및 캡처가 이뤄지므로 완벽한 심리적 안심을 제공합니다.

CASE STUDY 05

Independent Sensor MCU

OS 프리징 방지 & 타이밍 보장
01 / 사용자 문제 (USER CHALLENGE)

Jetson Linux OS에서 무거운 AI 모델이 연산 중일 때 센서 폴링이 지연되면, 사람이 다가와도 화면이 켜지지 않거나 LED 조명의 PWM 주파수가 불안정해져 카메라 화면에 검은 줄(밴딩)이 나타납니다.

02 / 선택한 기술 (SELECTED TECH)

ESP32-S3 보조 MCU를 분리 실장하여 하드웨어 PWM 타이머(25kHz 고주파)와 UART/I2C 실시간 센서 감시를 전담시키고, Jetson과는 USB-CDC 가상 시리얼 프로토콜로만 깔끔하게 연동했습니다.

03 / 기대 효과 (ENGINEERED OUTCOME)

Jetson의 연산 부하나 일시적 병목과 관계없이 1ms 이내의 무지연 센싱 응답과 롤링셔터 플리커가 0%인 안정적인 조명 제어가 상시 완벽하게 보장됩니다.

Operational Interaction Sequence

From Presence to Personalization.

거울 앞에 서서 맞춤 스타일링 결과를 마주하기까지, MUSE 하드웨어 내부에서 초 단위로 전개되는 정밀한 6단계 파이프라인 흐름입니다.

1 STANDBY ➔ WAKE

Presence Detection

초저전력 PIR 센서(HC-SR501)가 사용자의 접근을 감지합니다. 디스플레이 백라이트가 앰비언트 모드로 은은하게 켜지며 날씨와 시간을 표시합니다. 이 단계에서 카메라는 완벽히 비활성화 상태입니다.

동작 주체: ESP32-S3 (GPIO 감시)
2 USER INTENT

User-Initiated Capture

사용자가 거울 표면의 32인치 IR 터치 프레임 영역을 터치합니다. "스타일링 시작"을 사용자가 물리적으로 명시적 지시한 순간에만 캡처 시퀀스가 허가됩니다.

동작 주체: IR Touch Frame ➔ Jetson USB HID
3 CALIBRATION

Environment Check

ESP32-S3가 ToF(TFmini-S)로 사용자와의 물리적 거리(1.9~2.6m)를 확인합니다. 동시에 TCS34725 조도 센서가 주변 색온도와 실내 밝기 럭스(Lux)를 실시간 판독합니다.

동작 주체: TFmini-S (ToF) + TCS34725 (RGBC)
4 FLASH CAPTURE

Lighting & Dual Capture

5000K 고연색 LED가 25kHz PWM으로 점등되어 0.1초 동안 광학계를 안정화합니다. RealSense D455와 IMX477이 버스트 캡처를 동시 완료한 즉시 조명은 자동으로 꺼집니다.

동작 주체: 24V LED + D455 (RGB-D) + IMX477 (CSI)
5 LOCAL COMPUTE

Edge AI Processing

Jetson Orin NX가 D455 깊이 맵과 IMX477 텍스처를 기기 내에서 처리합니다. 관절 키포인트 추정, 의류 카테고리 파싱, 색상·소재 임베딩 벡터를 로컬 생성합니다.

동작 주체: Jetson Orin NX (100 TOPS INT8)
6 RENDER UI

Styling Experience

32인치 1000nit 디스플레이에 럭셔리 매거진 에디토리얼 레이아웃의 스타일링 추천과 가상 피팅(VTO) 결과가 오버레이됩니다. 사용자는 터치로 의류를 교체해 봅니다.

동작 주체: 32" Display + Cloud VTO API 연동
Prototyping Risk Mitigation

Built with Real-world Constraints in Mind.

책상 위 설계와 실제 시제품 제작 사이의 간극을 메우기 위해 사전 도출된 8대 핵심 엔지니어링 과제와 기구/광학 검증 체크리스트입니다.

ITEM 01 · 광학 감쇄 시제품 검증 예정

하프미러 뒤 카메라 광량 손실 (~70% 감쇄) 대책

30% 투과율 하프미러 뒤에 카메라를 배치할 경우 수광량이 70% 손실되어 저조도 노이즈가 발생합니다. 카메라 렌즈 영역만 하프미러 코팅을 마스킹한 전용 투명창을 제작하거나, 상단 베젤에 렌즈를 직접 노출시키는 기구 가공 방식을 1차 시제품에서 비교 시험합니다.

ITEM 02 · 레이저 반사 설계 시 고려사항

RealSense IR 패턴 및 ToF 레이저의 유리 반사 노이즈 방지

하프미러 유리에 850nm/940nm 적외선 레이저가 내부 난반사될 경우 RealSense 깊이 맵에 고스트 노이즈가 생성됩니다. ToF 센서와 D455 발광부를 하프미러 표면에 밀착 개스킷(Gasket)으로 차폐하거나 베젤에 물리적으로 분리 배치합니다.

ITEM 03 · 센서 투과 설계 시 고려사항

PIR 인체 감지 센서의 유리 투과 불가 특성

원적외선(8~14µm) 체온을 감지하는 PIR 센서는 일반 유리나 하프미러를 투과할 수 없습니다. 따라서 센서를 거울 뒤에 숨기지 않고, 하단 베젤 프레임에 프레넬 렌즈용 12mm 원형 타공 홀을 마련해 외부로 직접 노출 배치하도록 기구 설계를 확정했습니다.

ITEM 04 · 광학 간섭 시제품 검증 예정

IR 터치 프레임과 RealSense D455 프로젝터 간 간섭 시험

IR 터치 프레임이 방출하는 적외선 격자와 D455의 IR 프로젝터 주파수(850nm 대역)가 중첩될 가능성을 검토합니다. 캡처 시퀀스 진행 중(약 0.5초간) IR 터치 프레임의 스캔을 일시 중단하거나, 상호 간섭이 없는 파장 분리형 부품을 선정하여 테스트합니다.

ITEM 05 · 플리커 제어 설계 시 고려사항

LED 25kHz PWM 고주파 제어로 롤링셔터 밴딩 원천 차단

카메라 셔터 속도(1/120s~1/1000s)보다 낮은 주파수로 LED 조명을 조광할 경우 화면에 줄무늬 밴딩이 나타납니다. ESP32-S3의 하드웨어 타이머를 통해 가청 주파수를 넘어서는 25kHz 초고속 PWM을 구동함으로써 플리커프리 품질을 구현했습니다.

ITEM 06 · 열 환기 설계 시제품 검증 예정

Jetson, 디스플레이, SMPS 밀폐 하우징 열 환기 대책

풀 로드 시 내부 발열체 합산 전력은 약 150W에 달합니다. 굴뚝 효과(Chimney effect)를 유도하기 위해 섀시 최하단에 자연 흡기 슬롯을 배치하고, 상단에 저소음 유체 베어링 80mm 배기팬(ESP32 온도 연동 자동 가변 제어)을 실장합니다.

ITEM 07 · RF 통신 보장 설계 시 고려사항

금속 알루미늄 하우징 차폐 방지용 외장 Wi-Fi 안테나

프리미엄 질감을 위해 거울 프레임을 아노다이징 알루미늄으로 제작할 경우 패러데이 케이지 현상으로 무선 신호가 차단됩니다. Wi-Fi 6E AX210의 SMA 커넥터를 프레임 외부 상단 플라스틱 인서트 영역으로 인출하여 2x2 MIMO 안테나를 배치합니다.

ITEM 08 · 설치 및 폼팩터 시제품 검증 예정

설치 방식(벽걸이/스탠드) 및 패널 해상도(FHD vs 4K) 최종 결정

시제품 총중량(예상 16~19kg)을 고려하여 VESA 200x200 표준 마운트 및 전용 플로어 스탠드 겸용 구조로 브라켓을 설계합니다. 패널은 1차 시제품에서 FHD로 안정성을 검증한 후 양산 단계에서 4K(3840x2160) 패널 교체 적합성을 테스트합니다.
