# MUSE 데이터 전처리 기법 및 순서 제안서

**기준 데이터:** 가구 ID 001 현장 조사 (2026-10-07, 낮 시간대)

## 0. 조사 결과 해석 및 전제

### 0.1 해석 원칙

| 구분 | 처리 방식 |
|---|---|
| 단일 선택 항목에 여러 개가 체크된 경우 (B3, B4, C3, C5, C6, C7 등) | 시간대·위치·가구원에 따라 **조건이 그만큼 넓게 변한다**는 뜻으로 해석하고, 전처리를 최악 조건까지 대응하도록 설계했습니다 |
| J 샘플 데이터 미확보 | 실측 노이즈와 색 왜곡을 분석할 수 없어 **모든 수치 파라미터는 초기값(가정)**이며, 샘플 확보 후 재조정이 필요합니다 |
| 조사 가구 1곳 (K 요약 미작성) | 분포를 알 수 없으므로 001 가구 조건을 "어려운 가구의 대표 사례"로 보고 설계했습니다 |

### 0.2 핵심 조건 요약 (전처리 설계에 직접 영향을 주는 항목)

| 영역 | 관찰 결과 | 전처리 시사점 |
|---|---|---|
| 배경 | 걸린 옷·행거 다수(A5), 베이지 벽(A6), 유리·광택 가구·TV(A7) | 배경 의류 오인식 위험이 가장 높음. RGB만으로는 분리가 어렵고 **Depth 기반 분리 필수** |
| 조명 | 자연광+주광색+형광등 혼합(B1), 조도 100lux 미만~500lux 이상(B3), 색온도 3000K 미만~6000K 이상(B4), 측면 창(B2) | 주변 조명을 보정만으로 해결하기 어려움. **촬영 시 내장 LED로 조명을 지배**한 뒤 보정 |
| 사용자 | 정지 1초 미만도 있음(C3), 긴 머리·모자·가방 가림(C4), 맨발~신발(C5), 가구원 여러 명·키 150cm 미만 포함(C6, C7) | 버스트 촬영, 품질 게이트, 가림 처리, 사용자 식별, 신발 보정 모두 필요 |
| 의류 | 모든 보관 방식(D1), 바닥 펼침·착용 인식 선호(D2), 모든 색·패턴·특수 소재(D4~D6) | 입력 도메인별 파이프라인 분리, 반사·투명 소재 예외 처리 필요 |
| 트리거 | 카메라 상시 대기 **거부**(I3) | 접근 감지로 자동 촬영하는 PRD 설계는 이 가구에 쓸 수 없음. **수동 버튼 트리거**를 기본으로 하고, 지연 예산 계산은 버튼을 누른 시점부터 시작 |
| 네트워크 | 10~50Mbps 이상이지만 가끔 끊김(H2) | Edge 버퍼링, 멱등 재전송, 추천 결과 사전 캐싱 필요 |
| 개인정보 | 거부감 보통(I1), 기기 저장 및 학습 활용 동의(I2) | 얼굴 마스킹 후 전송, 원본은 기기 내 보관하여 전처리 재실행 가능 |

### 0.3 공통 설계 원칙

1. **분석용 이미지와 색상용 이미지를 분리합니다.** 검출·세그멘테이션용 입력에는 CLAHE나 감마 같은 비선형 향상을 적용하지만, 색 추출과 VTON용 입력에는 선형 색 보정만 적용합니다. 비선형 향상이 의류 색을 왜곡하기 때문입니다.
2. **일상 모드와 측정 모드를 분리합니다.** 일상 모드(착장 인식·코디 표시)는 C8에 따라 3초 이내, PRD 목표상 p90 2초 이내로 처리합니다. 측정 모드(월 1회 체형 측정)는 정확도를 우선하고 약 5초를 허용합니다.
3. **신뢰도가 낮은 데이터는 학습에 쓰지 않습니다.** 모든 전처리 단계에서 품질 점수를 기록하고, 기준 미달 데이터는 화면 표시에만 쓰고 개인화 학습에서는 제외합니다.

## 1. 사용자 신체 이미지 (RGB)

### 1.1 전처리 순서

| 순서 | 단계 | 기법/알고리즘 | 근거 (조사 항목) | 권장 초기 파라미터 (가정) | 위치 / 시간 |
|---|---|---|---|---|---|
| 1 | 촬영 트리거 및 거리 확인 | 터치 버튼 트리거 → ToF로 사용자 거리 측정 → 화면에 실루엣 가이드와 "한 걸음 앞으로/뒤로" 표시 | I3 카메라 상시 대기 거부, A2 2.0~2.5m | 유효 거리 1.9~2.6m, 벗어나면 촬영 보류 | Edge (MCU+UI) / 0.1초 |
| 2 | 조명 지배 | 촬영 순간 내장 LED를 5000K 고정, 사용자 위치 목표 조도로 점등 | B1 혼합 광원, B3 100lux 미만 포함, B4 넓은 색온도 범위 | 목표 조도 400~600lux, 조도 센서 피드백으로 LED 출력 조절 | Edge / 0.1초 (LED 안정화) |
| 3 | 버스트 촬영 | 30fps로 15프레임 연속 취득 (0.5초) | C3 정지 1초 미만 사용자 있음 | 측정 모드는 2초간 60프레임 | Edge / 0.5초 |
| 4 | 프레임 품질 게이트 | 블러 검출(Laplacian 분산), 노출 클리핑 비율, 프레임 간 움직임(옵티컬 플로) 점수화 후 상위 3프레임 선택 | C3 짧은 정지 | Laplacian 분산 ≥ 100 (720p 다운샘플 기준), 클리핑 픽셀 < 2%, 실패 시 재촬영 안내 | Edge / 0.05초 |
| 5 | 렌즈 왜곡 보정 | 공장 캘리브레이션 내부 파라미터로 Undistort | A4 높이 1.5~1.8m (하향 촬영) | 재투영 오차 < 0.3px로 캘리브레이션 | Edge / 0.01초 |
| 6 | 색 보정 (색상 브랜치) | LED 스펙트럼 기준 사전 보정된 CCM + 조도·색온도 센서 값으로 von Kries 순응 보정 → D65 기준 선형 sRGB로 변환 | B1, B4 혼합 광원, 측면 창(B2) 자연광 혼입 | 주변광 비율(센서 측정 조도 / LED 기여 조도)이 30% 초과 시 "색 신뢰도 낮음" 플래그 | Edge / 0.02초 |
| 7 | 대비 향상 (분석 브랜치 전용) | L 채널에만 CLAHE 적용 | D4 검정·흰색 옷 디테일 손실, A6 베이지 벽과 피부색 유사 | clipLimit 2.0, 타일 8×8 | Edge / 0.01초 |
| 8 | 타깃 사용자 선택 | 인물 검출 후 Depth 기준 가장 가깝고 화면 중앙에 있는 1명 선택, 반사 허상 제거 | A7 유리·TV 반사, C6 다인 가구 | 사람 bbox 중심이 화면 중앙 40% 이내, Depth 1.9~2.6m | Edge / 0.03초 |
| 9 | 사용자 식별 | 온디바이스 얼굴 임베딩(ArcFace 계열) 매칭 + 터치로 프로필 확인 | C6 1~3명 이상, C7 키 150cm 미만 포함 | 코사인 유사도 ≥ 0.5면 자동, 0.35~0.5는 확인 요청, 미만은 게스트 처리 | Edge / 0.03초 |
| 10 | 배경 분리 | **Depth 게이팅 ∩ Human Parsing** 교집합 마스크. 사용자 몸통 중앙값 깊이 ±0.4m 밖의 픽셀은 배경으로 처리 | A5 걸린 옷·행거, A6 베이지 벽 | 깊이 허용폭 ±0.4m, 경계는 가이디드 필터(r=8)로 정제 | Edge / 0.08초 |
| 11 | 신체·의류 파싱 | Human Parsing으로 상의·하의·아우터·신발·가방·머리카락·모자 영역 분리 | C4 머리카락·모자·가방 가림 | 클래스별 최소 면적 비율 0.5% 미만은 노이즈로 제거 | Edge / 0.15초 |
| 12 | 포즈 유효성 검사 (측정 모드) | 포즈 추정(RTMPose)으로 A-pose와 측면 자세 검증 | C2 대체로 가능 | 팔-몸통 각도 20~45° (허용 ±15°), 측면 회전 80~100°, 관절 신뢰도 < 0.5인 관절이 2개 이상이면 재촬영 | Edge / 0.05초 |
| 13 | 가림 처리 (측정 모드) | 어깨 키포인트가 머리카락에 가려지면 Depth 윤곽선으로 어깨폭 추정, 모자는 머리 상단 깊이로 정수리 추정, 가방은 제거 요청 | C4 | 어깨 신뢰도 < 0.5면 Depth 윤곽 대체, 가방 마스크 면적 > 3%면 촬영 전 제거 안내 | Edge / 0.02초 |
| 14 | 신발 높이 보정 (측정 모드) | 발 영역 파싱 결과로 신발 유형 분류 후 키에서 오프셋 차감. 측정 모드에서는 맨발/양말 촬영을 우선 안내 | C5 맨발~신발 혼재 | 맨발 0cm, 실내화 1.5cm, 운동화 3cm, 구두·부츠 4cm (가정, 실측 보정 필요) | Edge / 0.01초 |
| 15 | 얼굴 익명화 | 얼굴 영역 마스킹(불투명 처리) 후 마스크 좌표만 Edge에 보관 | I1 거부감 보통, PRD 개인정보 원칙 | 얼굴 bbox 20% 확장 후 마스킹 | Edge / 0.01초 |
| 16 | 크기 정규화 | 사람 bbox + 여백 10% 크롭, 용도별 리사이즈 | VTON·포즈 입력 규격 | VTON 1024×768, 포즈 256×192, 리사이즈는 INTER_AREA | Edge / 0.01초 |

## 3. 옷장 의류 이미지

또한 **컬러 패치와 크기 기준 마커가 인쇄된 MUSE 촬영 매트(약 1×1.2m)**를 기본 구성품으로 제공할 것을 권장합니다. 하나의 매트로 색 보정 기준, 크기 측정 기준, 깨끗한 배경을 동시에 해결할 수 있어 B1·B4의 조명 변동과 D1의 비정형 보관 문제를 한 번에 줄일 수 있습니다.

## 7. 가장 위험한 환경 조건 Top 3 및 예외 처리 전략

| 순위 | 위험 조건 | 관련 항목 | 발생 가능 문제 | 예외 처리 전략 |
|---|---|---|---|---|
| 1 | **배경에 걸린 옷 + 베이지 벽 + 반사체** | A5, A6, A7 | 배경의 옷을 사용자가 입은 옷으로 오인식, 피부·벽 경계 손실, 유리·TV에 비친 허상을 사람으로 검출 | ① 설치 시 빈 배경 깊이맵 등록 ② Depth 게이팅과 파싱 교집합으로만 착용 의류 인정 ③ 반사 영역 상시 마스크 ④ 사용자와 배경 행거 간 거리가 0.8m 미만이면 설치 위치 변경 권고 ⑤ 착용 의류가 3개 이상 같은 카테고리로 검출되면 오인식으로 보고 재촬영 |
| 2 | **혼합 조명 + 넓은 조도·색온도 변동 + 다양한 색·소재** | B1, B3, B4, B5, D4, D6 | 같은 옷이 시간대별로 다른 색으로 인식되어 색 취향 학습이 오염되고, 검정·흰 옷 디테일이 손실됨 | ① 촬영 시 LED로 조명 지배 ② 주변광 비율 30% 초과 시 색 신뢰도 낮음 표시 후 **색 취향 학습에서 제외** ③ 조도 100lux 미만에서 LED 최대 출력으로도 목표 조도 미달이면 색 인식 생략, 형태·카테고리만 사용 ④ 옷장 대표색은 매트 촬영(CCM 보정) 값을 기준값으로 고정하고, 미러 착용 인식 색은 매칭 보조 신호로만 사용 |
| 3 | **짧은 정지 + 가림 + 신발 혼재 + 다인 사용자** | C3, C4, C5, C6, C7 | 체형 치수 오차, 다른 가구원 데이터가 섞여 개인화 모델 오염 | ① 버스트 촬영과 품질 게이트로 최적 프레임 선택 ② 측정 모드 진입 시 "머리 묶기·모자 벗기·가방 내려놓기·맨발" 체크리스트 화면 표시 ③ 가림 관절은 Depth 윤곽으로 대체 ④ 얼굴 식별 + 터치 확인 2단계 사용자 귀속 ⑤ 식별 불확실 세션은 개인 학습 제외 ⑥ 키 150cm 미만 사용자는 프레임 하단 여유를 늘리도록 거리 가이드를 2.3m 이상으로 조정 |

**별도 주의 사항 (I3):** 이 가구는 카메라 상시 대기를 거부했으므로 PRD의 "접근 시 자동 기동"을 쓸 수 없습니다. 버튼 트리거 방식에서도 아침 코디 표시를 즉시 할 수 있도록, **추천 결과는 06:00에 서버에서 미리 계산해 Edge에 캐시**하고 버튼을 누르면 카메라 처리 전에 먼저 표시하는 구조를 권장합니다.

## 9. 불리한 현장 조건을 위한 설치 가이드 권고사항

| 조건 | 권고 사항 | 기대 효과 |
|---|---|---|
| 배경에 걸린 옷·행거 (A5) | 미러를 행거가 카메라 시야 **뒤가 아닌 옆**에 오도록 배치하는 것을 1순위로 권장. 불가능하면 사용자 위치와 행거 사이 깊이 간격을 0.8m 이상 확보하거나 행거 앞에 단색 커튼 설치 | Depth 게이팅만으로 배경 의류 분리 가능 |

| 측면 창 + 혼합 조명 (B1, B2) | 창이 사용자 **정면 또는 측면**에 오게 유지 (역광 금지). 오전 직사광이 들면 시폰 커튼 권장 | 노출·색 왜곡 감소 |
| 저조도 (B3 100lux 미만) | 드레스룸 천장 조명을 주광색 LED로 교체 권장, 미러 내장 LED는 항상 촬영 시 점등 | 블러·노이즈 감소, 색 신뢰도 향상 |
| 카메라 높이 (A4) | 카메라 렌즈 높이 1.5~1.7m, 하향 각도 10° 이내로 설치. 바닥에 2.2m 위치 표시 스티커 부착 | 전신 프레임 확보, 원근 왜곡 최소화 |

| 키 차이가 큰 가구원 (C7) | 바닥 위치 스티커를 2.0m(성인)와 2.3m(키 작은 가구원) 두 개로 표시 | 모든 가구원의 발끝까지 프레임 안에 포함 |
