Edge 온디바이스 처리

신체 이미지

2초 내 스타일링 제안이 완료되어야 하므로 모든 RGB 분석 및 얼굴 마스킹은 기기 자체 NPU에서 온디바이스로 완료됩니다.

IN4K 카메라 센서 RGB 스트림
OUT얼굴 비식별화 키포인트 맵 (1024×768)
  1. 버튼 터치 시에만 카메라 활성화항시 감시형 촬영을 배제하고 사용자 명시적 터치 시에만 세션이 오픈됩니다.
  2. 거리 센서 기준 거리 (1.9~2.6m) 확인거울과 사용자 사이 최적 피팅 화각을 확인하고 벗어날 시 스마트 가이드를 표시합니다.
  3. 내장 링 라이트 조사 후 15연사400~600 lux 균일 조명 하에서 0.5초 동안 초고속 버스트 캡처를 실행합니다.
  4. 모션 블러 평가 상위 3장 선별가장 흔들림이 적고 선명한 프레임 3장을 가중치 평가하여 픽업합니다.
  5. 카메라 렌즈 왜곡(Fisheye) 보정공장 출하 캘리브레이션 매트릭스를 기반으로 가장자리 왜곡을 수평 정렬합니다.
  6. ToF 심도 기반 실루엣 분리사용자 기준 ±40cm 이내의 신체 영역만 분리해 옷걸이 및 가구 노이즈를 완전 제거합니다.
  7. 얼굴 마스킹 및 실루엣 정규화외부 전송용 이미지는 얼굴 영역을 완전 블러링하고 체형 비율 데이터만 암호화 전송합니다.
Edge 온디바이스 처리

ToF 깊이 센서

거울, 유리 창문, TV 등의 광택 반사로 인한 3D 노이즈를 필터링하여 정확한 체형 치수(어깨, 가슴, 허리)를 산출합니다.

  1. 설치 공간 빈 배경 정적 맵 학습첫 부팅 시 30초간 빈 드레스룸의 심도 맵을 스캔해 반사 노이즈 좌표를 마스킹합니다.
  2. 유효 작동 심도 (0.5~3.5m) 클리핑지나치게 가깝거나 거울 뒤 가상 깊이 평면(허상)에 위치한 포인트는 즉각 배제합니다.
  3. 시공간 결합 필터링정적 프레임 간 가중 평균 및 바이래터럴 필터로 외곽선 에지를 정밀 보존합니다.
  4. 바닥 평면 수평 정렬 보정바닥면과의 각도를 계산해 스탠드 기울기가 2° 이상 틀어졌을 경우 알림을 발송합니다.
  5. 3D 포인트 클라우드 다운샘플링5mm 복셀 그리드로 압축해 실시간 체형 추정 모델의 인퍼런스 속도를 극대화합니다.
Cloud 파이프라인

스마트 클로젯 사진

MUSE 스마트 촬영 매트 위에 올려둔 옷을 모바일 앱으로 촬영하면 실제 규격, 직조 패턴, 대표 컬러를 자동 디지털화합니다.

  1. 매트 4코너 마커 투영 변환비스듬히 찍힌 모바일 사진을 1:1 수직 시점 정사영 영상으로 자동 교정합니다 (1px = 1mm).
  2. 컬러 패치 기반 광원 화이트밸런스 복원주변 조명의 색 왜곡을 색차 차트로 역산하여 실물 본연의 색상으로 캘리브레이션합니다.
  3. 의류 경계 자동 누끼 세그멘테이션매트 그린 스크린 영역과 경계를 분리하고 모헤어/시스루 소재 특성을 태깅합니다.
  4. CIE Lab 색공간 대표 3색 추출사람의 지각에 가장 부합하는 Lab 색공간에서 하이라이트를 배제한 베이스 컬러를 산출합니다.
  5. 실측 치수(총장, 어깨단면) 자동 계측픽셀당 밀리미터 단위를 기반으로 옷의 실측 치수를 데이터베이스에 바인딩합니다.
Cloud 일일 배치

제휴 쇼핑몰 카탈로그

29CM, W컨셉, 무신사 등 주요 파트너사의 신규 상품 정보를 표준 규격으로 매일 자동 인제스천합니다.

  1. 누끼 단독컷 / 모델 착용컷 분리AR 가상 드레이핑에 적합한 흰 배경 단독 상품 컷을 최우선 추출합니다.
  2. 브랜드별 사이즈 체계 표준화브랜드마다 상이한 S/M/L, 26/28 표기를 실측 밀리미터 단면 테이블로 통일 변환합니다.
  3. 고해상도 텍스처 맵 생성드레이핑 시 직물 결이 무너지지 않도록 1024×768 표준 텍스처 맵을 구성합니다.
Cloud 실시간 처리

날씨 & 일정 컨텍스트

외출 시간대 기온과 일정의 TPO 격식을 유기적으로 파싱해 출근 룩과 주말 캐주얼을 영리하게 분기합니다.

  1. 외출 체감온도 및 강수 확률 매핑종일 평균 기온이 아닌, 사용자가 외출하는 시간대의 풍속/체감온도를 타깃팅합니다.
  2. 일정 약어("ㄱㅅ 미팅" 등) 자연어 해석개인 캘린더 사전 및 LLM 컨텍스트 파서로 TPO 포멀 지수(1~5단계)를 추출합니다.
  3. 프라이버시 익명화일정 세부 텍스트는 영구 저장하지 않으며 '격식 미팅, 실내 위주' 메타데이터만 활용합니다.
Hybrid 처리

착용 피드백 & Style DNA

거울에서의 선택(Wear / Pass / Swap)과 모바일 피드백을 가공해 취향 DNA를 점진적으로 정교화합니다.

  1. 7일 로컬 오프라인 큐와이파이가 일시 단절되어도 거울 로컬 스토리지에 반응을 안전 보관 후 재동기화합니다.
  2. 시간 감쇠(Time-decay) 가중치 적용계절 변화와 취향 이동을 고려하여 60일 이전 선택은 반영 가중치를 50% 감쇠합니다.
  3. 버튼 연타 및 오작동 필터1초 이내 발생한 중복 입력은 단일 신호로 정규화하여 학습 왜곡을 방지합니다.
Post-Processing Guardrails

거울에 비추기 전, 엄격한 품질 검증

AI 모델이 생성한 결과가 아무리 시각적으로 그럴듯해도, 왜곡된 체형이나 잘못된 색상은 잘못된 쇼핑과 실망으로 이어집니다. MUSE는 다음 기준을 통과한 결과물만 렌더링합니다.

검증 매트릭스 & 폴백(Fallback) 정책

AR Engine Guard Rule 01

가상 피팅 이미지 검증

생성형 가상 피팅은 체형을 인위적으로 날씬하게 왜곡하기 쉽습니다. MUSE는 본래 체형 마스크와 85% 이상 일치하지 않는 피팅 이미지는 절대 노출하지 않습니다.

IN생성된 드레이핑 프레임, 실측 신체 마스크

Core Philosophy

MUSE가 고수하는
4대 원칙

  • 01. 원본 신체 영상은 집 밖으로 나가지 않습니다 모든 얼굴과 신체 실루엣 측정은 거울 내부 온디바이스 NPU에서 완결되며, 클라우드에는 익명화된 수치만 전송됩니다.
  • 02. 불확실한 데이터로 취향을 학습하지 않습니다 조명이 불균일하거나 본인 확인 신뢰도가 낮은 날의 선택은 화면에만 임시 표시하고 Style DNA 학습 데이터셋에서 배제합니다.
  • 03. 판매 목적의 편향을 두지 않습니다 메인 코디 추천은 항상 사용자가 옷장에 보유한 옷이 최우선이며, 미보유 쇼핑 상품은 별도 옵션으로만 명확히 구분 제안합니다.
  • 04. AI 생성의 실패는 숨기지 않습니다 조명이나 왜곡으로 인해 피팅 품질이 기준에 못 미칠 경우 어설픈 합성 대신 실측 치수 비교표로 정직하게 전환합니다.
