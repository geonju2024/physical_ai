왜 SBC를 선택했을까?

MUSE는 단순한 장치 제어뿐 아니라 고해상도 영상 분석, 여러 AI 모델 추론, 화면 렌더링을 수행해야 합니다. 따라서 메인 연산 장치로 GPU 가속이 가능한 SBC 기반 시스템을 선정했습니다.
