SEVEN SPECIALIZED MINDS

Meet the Minds of MUSE.

사용자를 이해하고, 옷을 분석하고, 가장 잘 어울리는 스타일을 제안하기 위해 상호보완적으로 작동하는 7개의 특화 AI 모듈.

01. BODY EDGE / CLOUD 검증 중

Understand Your Shape

MediaPipe Pose Landmarker + SegFormer / SCHP

학습 방식: Pretrained + Rule-based
주요 역할: 신체 비율, 어깨/골반 라인 측정
Why We Chose It:

경량 포즈 추정 모델을 엣지 기기에서 활용하는 방안을 검토합니다. 실제 처리 속도와 개인정보 보호 성능은 시제품에서 측정합니다.

02. SMART CLOSET CLOUD

Know Your Wardrobe

SAM 2 + SigLIP Multi-Attribute Heads

학습 방식: Zero-shot → Fine-tuning
주요 역할: 옷장 의류 자동 누끼 및 속성 태깅
Why We Chose It:

배경과 옷걸이가 섞인 복잡한 사진에서도 의류의 정확한 실루엣을 분리해내어 카탈로그 수준으로 디지털화합니다.

03. FASHION DNA CLOUD

The Language of Style

FashionSigLIP / FashionCLIP

학습 방식: Frozen Encoder + LoRA
주요 역할: 패션 시맨틱 벡터 공간 투영
Why We Chose It:

텍스트와 비주얼 간 패션 어휘를 이해하여 "미니멀 린넨 셋업"과 같은 복합 스타일 감성을 정량 벡터로 해석합니다.

04. STYLE MATCHING CLOUD

Find What Works Together

OutfitTransformer Family

학습 방식: Polyvore Compatibility Fine-tune
주요 역할: 다중 아이템 조화도 점수화
Why We Chose It:

단순 1:1 매칭을 넘어 아우터, 상의, 하의, 신발 간의 전체적 균형미와 색상 대비를 총괄적으로 연산합니다.

Core Differentiator
05. LEARN ME CLOUD ADAPTIVE

Learn Your Preferences

Personalized Preference Ranking & Habit Feedback Vector

학습 및 적응 방식:

Rule-based Hard Filtering + User Preference Vector Adaptive Re-ranking

핵심 역할:

사용자가 실제로 자주 입는 핏, 기피하는 색상, 아침마다 선택한 룩북 피드백 반영

Why We Chose It (MUSE의 심장):

패션 데이터셋의 일반적인 스타일이 아무리 훌륭해도 "사용자 본인이 거울 앞에서 어색해하는 옷"은 실패한 추천입니다. LEARN ME는 사용자의 데일리 착용 결정 로그를 바탕으로 오직 단 한 사람만을 위한 맞춤 가중치로 추천 순위를 실시간 재구성합니다.

06. VIRTUAL FIT CLOUD GPU

See It Before You Wear It

CatVTON / IDM-VTON / High-End VTO API

접근 방식: Pretrained Inference / API-first
주요 역할: 사실적 드레이프 합성 및 주름 시뮬레이션
Why We Chose It:

옷을 실제로 갈아입지 않고도 거울 디스플레이 안에서 실물에 가까운 핏감과 실루엣을 직관적으로 확인하도록 지원합니다.

07. AI STYLIST CLOUD LLM

Explain the Choice

LLM with Structured Evidence Reasoning

학습 방식: Prompt Engineering + Context Injection
주요 역할: 날씨·체형·TPO 맞춤형 감성 설명문 생성
Why We Chose It:

단순 점수 출력이 아닌 신뢰할 수 있는 구체적 근거를 감각적인 언어로 사용자에게 전달하여 착용 결정을 돕습니다.

LEARNING PIPELINE

How MUSE Learns.

“이미 학습된 지식에서 출발해, 나만의 취향을 이해하기까지.”

MUSE의 학습은 단발성 모델 학습이 아닌 점진적 고도화 파이프라인으로 설계되었습니다. 각 단계는 엄격한 품질 게이트(Gate)를 통과할 때만 다음 단계로 전환됩니다. ※ 본 로드맵은 MUSE 팀의 향후 연구 개발 및 실증 계획을 나타냅니다.

STAGE 00

Zero-shot Baseline

사전학습된 기반 모델을 추가 훈련 없이 거울 인터페이스에 연결해 초기 기준 성능을 정량화하고 예외 상황(Edge Cases)을 수집합니다.

Gate 01 Requirement

초기 성능과 지연 시간 기준선 측정 완료

STAGE 01

Fine-tuning

DeepFashion2 및 Polyvore 데이터셋을 기반으로 전용 속성 분류 헤드와 호환성 점수 연산 모듈을 패션 도메인 데이터로 추가 학습합니다.

Gate 02 Requirement

실제 거울 카메라 화각에서의 세그멘테이션 mIoU 0.80 달성

STAGE 02

Real-world Adaptation

스마트 미러가 설치되는 가정 내 실내 조명(할로겐/LED), 역광, 다양한 신체 거리에 대응하는 도메인 적응(Domain Adaptation)을 거칩니다.

Gate 03 Requirement

실사용자 사용자 비교 실험에서 규칙 기반 추천 대비 수용률 개선 확인

STAGE 03

Personalization

사용자의 실제 거울 앞 선택 로그와 "오늘 이 옷 착용하기" 터치 반응을 반영하여 개인화 벡터를 점진적으로 업데이트합니다.

Ongoing Continuous Loop

시간순 평가에서 개인화 추천이 비개인화 기준선을 개선

TECHNICAL ROADMAP

What We're Solving Next.

상용화 거울 제품이 되기 위해 우리가 해결하고 있는 4대 핵심 엔지니어링 도전 과제와 개발 마일스톤입니다.

CHALLENGE 01 dataset

Data Scarcity (데이터 희소성)

사용자별로 수집되는 옷장·선호 데이터가 적은 초기 상황에서 딥러닝 모델의 콜드 스타트 문제를 해결해야 합니다. 해결책: 방대한 사전학습 모델의 범용 표현력과 스타일리스트의 규칙 기반(Rule-based) 코디 알고리즘을 하이브리드로 결합해 초기 추천 성능을 확보하는 방안을 검토합니다.

CHALLENGE 02 wb_incandescent

Real-world Lighting & Distortion (실내 환경 왜곡)

가정 내 주백색/전구색 등 복합 조명과 미러 전면 렌즈 왜곡으로 인해 옷의 실제 색상(네이비 vs 블랙)과 핏감이 왜곡될 위험이 있습니다. 해결책: 화이트밸런스 보정과 카메라 왜곡 보정의 적용 가능성을 실제 촬영 데이터로 검증할 계획입니다.

CHALLENGE 03 lock

Privacy & User Trust (프라이버시와 신뢰)

드레스룸이라는 가장 사적인 공간에서 사용자가 안심하고 전신 거울을 바라볼 수 있는 신뢰 체계를 세워야 합니다. 해결책: 엣지 우선 처리를 검토하고, VTON용 이미지 전송 시 별도 동의를 받으며 최소 수집·일시 처리·삭제 정책을 설계합니다.

CHALLENGE 04 memory

Edge Optimization & Licensing (온디바이스 최적화)

임베디드 보드의 발열과 전력 소모를 억제하면서 오픈소스 라이선스 제약(GPL 등)을 안전하게 피해야 합니다. 해결책: ONNX·양자화 등 경량화 방식을 비교하고, 채택 후보 모델과 학습 데이터의 상업적 이용 조건을 개별 검토할 계획입니다.
