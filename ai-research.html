AI MODEL STRATEGY · MVP

Simple by Design.

필요한 만큼만, 가볍게.

MUSE MVP는 직접 운영하는 AI 모델 2개와 외부 파트너 API 2개, 그리고 코드로 작성한 스타일링 규칙 엔진으로 구성합니다. 필요한 곳에만 AI를 쓰고, 나머지는 검증 가능한 규칙과 데이터 처리로 해결하는 것을 목표로 개발·검증 중입니다.

2
AI Models

직접 운영하는 AI 모델: MediaPipe, FashionSigLIP

2
Partner APIs

외부 연동 AI 서비스: Vision LLM, VTON

0
Model Training

MVP 단계 재학습 없음: FashionSigLIP 가중치는 고정하고, Wear/Pass 이력으로 별도 취향 벡터만 갱신

* MVP 설계 기준 구성이며, 실측 성능 지표가 아닙니다.

SYSTEM ARCHITECTURE

One Mirror. Light Intelligence.

나를 읽는 일은 거울 안에서, 코디를 고르는 일은 MUSE 서버에서, 옷을 읽고 입혀 보는 일은 파트너 API가 맡습니다.

Perceive Me

Internal Components

Internal Components

External Services

PIPELINE SUBSYSTEM

Wardrobe Registration Flow

촬영부터 디지털 옷장 메타데이터 생성까지의 4단계 데이터 변환

STEP 01 CAPTURE

촬영 매트 위 의류 촬영

표준 촬영 매트 위에 옷을 펼쳐 정면에서 촬영

STEP 02 REMOVE

크로마키 배경 제거

단색 매트 대비 색상 기반 마스킹 (AI 모델이 아닌 이미지 처리 코드)

STEP 03 TAG

Vision LLM 속성 태깅

종류·색상·패턴·계절·소재·케어라벨을 JSON으로 받아 스키마 검증

STEP 04 SAVE

디지털 옷장 등록

서버에서 FashionSigLIP 임베딩 생성 후 디지털 옷장에 저장

Five Parts. One Stylist.

신체 포즈 · 깊이 정보 · 손짓 조작

※ 사전학습 모델 사용 · 엣지에서 실행 · ToF 기반 체형 추정의 정확도는 실기기에서 검증 예정

※ MUSE 서버에서 실행 · 모델 가중치 고정, MVP 단계 재학습 없음 · 개인화는 별도 취향 벡터 갱신 로직이 담당

Vision LLM API

의류 태깅 · 케어라벨 분석 · 추천 이유

※ 외부 API · 케어라벨도 Vision LLM이 함께 읽음(별도 OCR 모델 없음) · 옷장 등록에 필요한 사진만 전송 · JSON 응답 스키마 검증

styler TRY-ON · PARTNER API

VTON API

AI 착용 이미지 생성

없는 옷도 2D 가상 피팅 이미지로 미리 확인할 수 있도록 합니다. 생성 모델과 GPU 서버는 직접 운영하지 않으며, 실시간 3D AR 드레이핑과는 다릅니다.

※ 사용자의 별도 동의를 받은 이미지만 전송 · 결과 품질 검사 후 실패 시 상품 정보로 대체 안내

※ AI 모델이 아닌 서버 코드 · 날씨·일정 필터, 최근 7일 반복 방지, 캐싱·폴백 처리 포함
